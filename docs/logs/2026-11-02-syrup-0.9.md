## Baseline and authorization

On 2026-11-02 the maintainer approved committing the Fn work, bumping to 0.9, and publishing it, unless tests fail or anything in the Fn work is shaky. Earlier the maintainer had requested 0.9 would also carry three speech models, Home stats, self-corrections, and spoken formatting. Those are not built.

- Previous distribution: 0.8 build 8, published as `v0.8`.
- Isolated suite on the Fn code: 560 tests in 69 suites passed.

## What is unverified

- A dictation with a physical Fn key has not run in Syrup itself. FnProbe proved the same system calls see Fn on the built-in keyboard; the hold, double-tap, and tap logic above that has only simulated key states.
- Fn with another physical key, an external Apple keyboard, and macOS Dictation's Press Fn Twice shortcut are untested. The external keyboard that does not send Fn sends no Fn, so Fn does nothing there.
- An in-app update has not been observed from 0.8 to 0.9. This release is the first that can test it.
- The installed app was not replaced.
- 0.9 contains only the Fn trigger, the Home text for it, and its hint. The three speech models, Home stats, self-corrections, and spoken formatting are not in it.
